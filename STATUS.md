## Ключевые находки (сверены с живым кодом прошлого проекта)

1. **mrkt фильтрует по TLS-отпечатку.** `IMPERSONATE = "chrome124"`.
   Нужен `curl_cffi`; обычные httpx/aiohttp отсекаются до приложения.
   Источник: `~/Desktop/trash code/mrkt/config.py:41-43`.
2. **Базовый URL:** `https://api.tgmrkt.io/api/v1`, CDN `cdn.tgmrkt.io`.
3. **Ссылка на подарок:** `https://t.me/nft/{slug}-{number}`, разделитель —
   дефис. Источник: `config.py:32`.
4. **Экономика:** комиссия 2%, но газ 0.10 TON на покупку и 0.10 на продажу.
   На лотах 2–5 TON газ превышает комиссию — формулировка «без комиссий»
   неточна, и это стоит сказать пользователю в интерфейсе.
5. **Троттлинг:** 0.55 с между запросами, откат 12 с, таймаут 20 с.
6. **Стакана ордеров у mrkt не найдено** ни в одном источнике. Есть только
   `offers/create` по `giftSaleId` — оффер на конкретный лот, другая
   механика. Решение владельца: показывать самый высокий ордер.

## Ограничения среды, в которой это писалось

- **`git init` в проекте запрещён песочницей** (`.git: Operation not
  permitted`). Пуш на GitHub из этой сессии невозможен: нужен запуск вне
  песочницы либо `git init` вручную.
- **Сети нет:** PyPI за прокси отдаёт 403, установить пакеты нельзя.
  Поэтому тесты на `unittest` из stdlib, а не на pytest.
- **Docker локально отсутствует** — Dockerfile нельзя проверить сборкой.
- В `/Users/pexepo` лежит пустой случайный `.git` (0 коммитов, 0 файлов,
  без remote). Он не тронут. Если он не нужен — удалить: иначе коммит из
  домашней папки затянет `.ssh/` и `.claude.json` в публичный репозиторий.
